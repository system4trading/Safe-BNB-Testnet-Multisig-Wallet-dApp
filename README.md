Safe BNB Testnet Multisig Wallet dApp supported by only injected web wallets for testing purpose in Chapel/ BNB Testnet. 
Safe BNB Testnet Multisig Wallets using injected wallets can be created through 'https://multisig.bnbchain.org'.
Safe BNB Testnet Multisig Wallet is not supported by Mobile wallets and WalletConnect.
